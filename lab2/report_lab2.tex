\section{Scopul lucrării}
Implementarea primului program în spațiul utilizator (user-space) pentru sistemul de operare educațional xv6: utilitarul \texttt{sleep}.

\section{Desfășurarea lucrării}
\subsection{Codul sursă (\texttt{sleep.c})}
Deoarece sistemul xv6 curent nu suportă apelul standard \texttt{sleep()} direct în modul cerut, am implementat pauza folosind un loop cu apelul de sistem \texttt{pause()}.
\begin{lstlisting}[language=C]
#include "kernel/types.h"
#include "kernel/stat.h"
#include "user/user.h"

int main(int argc, char *argv[]) {
  if(argc < 2){
    fprintf(2, "Usage: sleep ticks\n");
    exit(1);
  }
  int ticks = atoi(argv[1]);
  for (int i = 0; i < ticks; i++) {
      pause();
  }
  exit(0);
}
\end{lstlisting}

\section{Răspunsuri (Observe)}
\begin{enumerate}
    \item \textbf{Cum este recunoscut noul program de către sistem?} Pentru ca xv6 să compileze și să includă comanda \texttt{sleep} în sistemul său de fișiere, fișierul sursă trebuie adăugat în \texttt{Makefile} la secțiunea \texttt{UPROGS}, sub forma \texttt{\$U/\_sleep}.
\end{enumerate}

\section{Concluzii}
Adăugarea unui utilitar nou în xv6 presupune scrierea codului C bazat pe apelurile expuse în \texttt{user.h} și modificarea lanțului de compilare (\texttt{Makefile}). Adaptarea funcției prin \texttt{pause()} demonstrează necesitatea de a lucra cu primitivele specifice nucleului curent.
